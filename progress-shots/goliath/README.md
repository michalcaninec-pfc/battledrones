# Goliath and Gantry (GOLIATH.md)

Rendered with the procedural three.js models (`src/game/three/goliath.ts`,
`src/game/render/goliath.ts`): gallery shots from `tools/models.html`
(`?only=goliath`, `?only=gantry`) and in-game shots from a skirmish on Proving
Grounds, Chromium headless with SwiftShader. All taken 2026-10-12.
